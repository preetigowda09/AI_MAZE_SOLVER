# AI Maze Solver

A Python-based AI maze solver implementing BFS, DFS, and A* Search algorithms.

## Algorithms Implemented
- **BFS (Breadth First Search)** - Finds shortest path
- **DFS (Depth First Search)** - Explores deep paths first
- **A* Search** - Uses heuristic for optimal path

## How to Run
```bash
python maze_bfs.py
python maze_dfs.py
python maze_astar.py
